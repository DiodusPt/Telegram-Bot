# Инвентаризатор
Телеграм - бот для проведения инвентарного учета в организации.
## Описание
Бот позволяет:
* вести учёт объектов по кабинетам;
* добавлять объекты с подробной информацией (модель, производитель, серийный номер);
* просматривать содержимое кабинетов;
* искать объекты по различным критериям;
* удалять объекты и кабинеты.

Работает прямо в Telegram — не требует установки отдельного приложения.
## Функционал

* **📦 Добавить кабинет** — регистрация новых помещений.
* **➕ Добавить объект** — внесение предметов с указанием модели, производителя, серийного номера и описания.
* **👀 Посмотреть содержимое** — просмотр всех объектов в выбранном кабинете.
* **🔍 Расширенный поиск** — поиск по названию, модели, производителю или серийному номеру.
* **🗑️ Удалить объект** — удаление отдельных позиций из кабинета.
* **⛔ Удалить кабинет** — удаление кабинета (если в нём нет объектов).
* **ℹ️ Справка** — подсказка по работе с ботом.
