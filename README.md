# Инвентаризатор
## Описание
Данный бот предназначен для организаций, которые хотят автоматизировать процесс инвентаризации имущества. Бот создает базу данных, в которой есть две таблицы: Кабинеты и Предметы. В таблице "Кабинеты" прописываются названия кабинетов. В таблице "Объекты" прописываются кабинет, в котором находится объект, его название, количество и описание.
